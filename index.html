How to install an APK

  1. Tap Download APK on the app you want.
  2. Open the downloaded file from your notifications or the Downloads folder.
  3. If Android asks, allow your browser or file manager to install unknown apps.
  4. Tap Install, then Open.

Questions

Is it safe?

Every APK is built from the source code in this GitHub repository and uploaded to GitHub Releases. You can read the code and compare file sizes before installing.

Why does Android show a warning?

Android warns about any app that doesn’t come from the Play Store. It’s a general warning, not a sign that this file is bad.

An app won’t install. What now?

Check that your Android version meets the app’s minimum, and that you have enough free storage. If it still fails, open an issue on GitHub and include your phone model.
